# BELJOUR — Full Beauty Studio (website)

The public landing page for **Beljour**, a full beauty studio for your own photos: skin, makeup, hair, photo fixes, video and filters in one private studio.

Live site: https://alenzacodes.github.io/beljour-site/

This repository holds only the static landing page (`index.html`, `style.css`, `assets/`). There is no build step. The Beljour app itself is developed in a separate private repository.

Built by [ALENZA CODES](https://alenzacodes.github.io/john-khan-site/), Toronto, Ontario.
